# AruShell

**AruShell** — полноценная настольная оболочка (Desktop Shell) в стиле **Material 3 Expressive (Material You)** с живыми музыкальными клипами, синхронизированными текстами песен, Dynamic Island, скриншотером и темой SDDM, написанная на **Quickshell (Qt6 QML)**.

> **Важно:** AruShell изначально создавался и тестировался под **Hyprland** (поддерживаются как новый Lua-конфиг `0.55+`, так и классический `hyprland.conf`). Установщик умеет ставить зависимости на разные дистрибутивы Linux, но полная функциональность рабочих столов, выбора окон и биндов рассчитана на Hyprland.

---

## Возможности

* **Верхняя панель (exclusive zone 48px)**:
  * **App Launcher** (шейп Material 3 Expressive `ghost` с 360° вращением, бинд на `SUPER`): поиск приложений с оригинальными иконками, переключение открытых окон Hyprland, пикер эмодзи и системные команды.
  * **Pac-Man Workspaces**: анимированный Пакман, который переезжает и «съедает» точки рабочих столов.
  * **Dynamic Island (пилюля)**: компактная пилюля с круглой обложкой, часами, погодой и эквалайзером; раскрывается на 3 секунды при уведомлениях и в 3-вкладочную карточку (**Dashboard** с календарём и погодой | **Media** с мягкой квадратной обложкой и волнистым скраббером | **Performance** с волнистыми круговыми графиками CPU/RAM/Disk), с автозакрытием при уходе курсора.
  * **Системная зона**: сворачиваемый трей (оригинальные цвета иконок), индикатор раскладки `RU/EN`, системная пилюля (иконки в стиле iOS) с **Quick Settings** (подменю Wi-Fi, Bluetooth, переключения аудиовыходов, ночной свет `hyprsunset`, профили питания, волнистые ползунки звука/яркости) и кликабельный **Центр уведомлений** (шейп `Soft Gem`).
* **Рабочий стол и музыка**:
  * **Живые музыкальные клипы** (автопауза при остановке песни и при открытии любых приложений — клип играет только на пустом столе), динамическая палитра Material You из обложки, шрифт **Google Sans**.
  * **Адаптивная сцена**: без текста песни обложка встаёт ровно по центру, а при появлении текста мягко отъезжает влево и открывает синхронизированные слова (Яндекс Музыка + LRCLIB).
  * **ПКМ на рабочем столе**: контекстное меню управления столом и живой перенос виджетов мышкой.
  * **Окно настроек всего шелла** (`SettingsWindow.qml`) с сохранением в `settings.json`.
* **Утилиты**:
  * **Скриншотер с заморозкой экрана** (`SUPER + Shift + S` / `Print`): область с круглой лупой и ручками, выбор окон Hyprland, весь экран, сохранение + буфер, плавающий редактор `satty`/`swappy`.
  * **Менеджер буфера обмена** (`SUPER + V`, `cliphist`).
  * **Волнистый OSD** при изменении громкости, яркости и раскладки.
  * **Автоскрываемый / закрепляемый нижний док** с оригинальными иконками приложений и мини-плеером.
  * **Тема входа SDDM** (`sddm-theme/arushell-material-you/`) в едином стиле Material You + Google Sans.

## Установка

```bash
git clone https://github.com/Arytemu/AruShell.git
cd AruShell
./install.sh
```

Для автоматической установки без вопросов:

```bash
./install.sh --yes
```

### Поддерживаемые дистрибутивы

| Дистрибутив | Пакетный менеджер | Примечание |
| :--- | :--- | :--- |
| **Arch Linux / CachyOS / EndeavourOS / Manjaro** | `pacman` + `yay`/`paru` | Основная платформа (полная автоустановка + AUR) |
| **Fedora / Nobara** | `dnf` | Зависимости ставятся автоматически; `quickshell` из COPR |
| **Debian / Ubuntu / Pop!_OS** | `apt` | Ставит Qt6 и утилиты; `quickshell` собирается из исходников |
| **openSUSE Tumbleweed** | `zypper` | Ставит Qt6 и утилиты |
| **NixOS** | `nix` | Выводит список пакетов для `configuration.nix` и ставит конфиг |

### Установка темы SDDM

```bash
./install_sddm_theme.sh
```

Превью без перезагрузки:

```bash
sddm-greeter-qt6 --test-mode --theme /usr/share/sddm/themes/arushell-material-you
```

## Горячие клавиши (Hyprland)

| Клавиши | Действие |
| :--- | :--- |
| `SUPER` (тап) | Открыть / закрыть App Launcher |
| `SUPER + V` | Менеджер буфера обмена (`cliphist`) |
| `SUPER + Shift + S` / `Print` | Скриншотер (область / окно / экран) |
| `Shift + Print` | Мгновенный скриншот всего экрана |
| `ПКМ` на рабочем столе | Меню управления столом и перенос виджетов |
