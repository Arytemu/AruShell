# AruShell

**AruShell** — настольная оболочка (Desktop Shell) в стиле **Material 3 Expressive (Material You)** для **Hyprland**, написанная на **Quickshell (Qt6 QML)**. Включает экран блокировки в стиле Caelestia, 4-вкладочный Dynamic Island, живое перекрашивание HUD под текущие обои, карусель обоев, конструктор быстрых настроек, живые музыкальные клипы, скриншотер и тему SDDM.

> **Примечание:** AruShell изначально создавался и тестировался под **Hyprland** (поддерживаются новый Lua-конфиг `0.55+` и классический `hyprland.conf`). Установщик ставит зависимости на разные дистрибутивы Linux, но рабочие столы, выбор окон и бинды рассчитаны на Hyprland.

## Возможности

* **Экран блокировки в стиле Caelestia (`SUPER + L` и автолок 10 мин в `hypridle`)**:
  * Двухфазная анимация: плавное размытие живого рабочего стола (`ScreencopyView`), появление наклонённого значка замка и разворачивание в парящую 3-колоночную bento-карточку.
  * Крупные часы шрифтом **Bebas Neue**, аватар из `~/.face`, анимированные M3-шейпы ввода пароля, погода, `arushellfetch.sh` с динамической палитрой, медиа-карточка, вертикальные индикаторы CPU/RAM/BAT и уведомления.
* **Dynamic Island (4 вкладки, автоподстройка размера)**:
  * Компактная пилюля с обложкой, часами, датой, погодой и эквалайзером; всплывающие уведомления на 3 секунды.
  * Раскрывается в 4 вкладки с плавным кросс-фэйдом: **Dashboard** (календарь + погода), **Media** (плеер + синхронизированный текст песни), **Performance** (волнистые датчики CPU/RAM/Disk + живая скорость сети `↓/↑` из `/proc/net/dev`) и **Weather** (влажность, ветер и прогноз на 3 дня).
* **Карусель обоев (`SUPER + W`) и Material You**:
  * Переключение обоев стрелками, добавление своих папок и автоматическое перекрашивание всего HUD под доминантный цвет текущих обоев.
  * Переключение **Тёмной / Светлой темы** и прозрачности панелей в настройках.
* **Верхняя панель и конструктор QuickSettings**:
  * **App Launcher** (`SUPER`, шейп `ghost` с 360° вращением или **своя картинка**): поиск приложений с оригинальными иконками, открытые окна Hyprland, эмодзи и системные команды.
  * **Pac-Man Workspaces**: Пакман переезжает и «съедает» точки рабочих столов; urgent-воркспейсы (например, открытая в браузере ссылка) пульсируют красным, пока Пакман их не съест.
  * **QuickSettings-конструктор («Изменить»)**: добавление и удаление плиток/значков пилюли, ширина плиток `1× / 2×`, настройка ширины меню, высоты плиток, отступов и размера иконок; рабочий выбор Wi-Fi с паролем (без фоновых сканов и лагов сети), Bluetooth, выбор аудиовыхода, Ночной свет (`hyprsunset`), **Игровой режим (Game Mode)** и **Не засыпать (Keep Awake)**.
  * **Мгновенный OSD** громкости, яркости, режимов и раскладки клавиатуры (`activelayout` через Hyprland IPC).
* **Музыка и рабочий стол**:
  * Поддержка нативных и Electron-плееров (MPRIS) с выбором клиента (**Авто**, **Яндекс Музыка**, **Spotify**, **Apple Music**, **YT Music**, **Tidal**, **Deezer**, **MPD**, **Свой**) — браузеры и Telegram Web игнорируются.
  * Живые музыкальные клипы (автопауза при открытии окон; скрываются при закрытии плеера), синхронизированные тексты песен (Яндекс Музыка + LRCLIB), перенос виджетов мышкой (ПКМ по рабочему столу), автоскрываемый/закрепляемый нижний док.
* **Скриншотер (`SUPER + Shift + S` / `Print`) и утилиты**:
  * Заморозка экрана, выделение области с круглой лупой и ручками, выбор окон Hyprland, плавающий редактор `satty`/`swappy`.
  * Буфер обмена (`SUPER + V`, `cliphist`), окно настроек в стиле Control Center с поиском и вкладкой «О системе», тема входа **SDDM** (`sddm-theme/arushell-material-you/`).

## Установка и обновление

```bash
git clone https://github.com/Arytemu/AruShell.git
cd AruShell
./install.sh
```

Быстрое обновление файлов и биндов за 1 секунду (без переустановки пакетов и с сохранением настроек):

```bash
./update.sh
```

### Поддерживаемые дистрибутивы

| Дистрибутив | Пакетный менеджер | Примечание |
| :--- | :--- | :--- |
| **Arch Linux / CachyOS / EndeavourOS / Manjaro** | `pacman` + `yay`/`paru` | Основная платформа (полная автоустановка + AUR) |
| **Fedora / Nobara** | `dnf` | Зависимости ставятся автоматически; `quickshell` из COPR |
| **Debian / Ubuntu / Pop!_OS** | `apt` | Ставит Qt6 и утилиты; `quickshell` собирается из исходников |
| **openSUSE Tumbleweed** | `zypper` | Ставит Qt6 и утилиты |
| **NixOS** | `nix` | Выводит список пакетов для `configuration.nix` и ставит конфиг |

### Установка темы SDDM

```bash
./install_sddm_theme.sh
```

Превью без перезагрузки:

```bash
sddm-greeter-qt6 --test-mode --theme /usr/share/sddm/themes/arushell-material-you
```

## Горячие клавиши (Hyprland)

| Клавиши | Действие |
| :--- | :--- |
| `SUPER` (тап) | Открыть / закрыть App Launcher |
| `SUPER + W` | Карусель обоев (стрелки + свои папки) |
| `SUPER + L` | Экран блокировки в стиле Caelestia |
| `SUPER + V` | Менеджер буфера обмена (`cliphist`) |
| `SUPER + Shift + S` / `Print` | Скриншотер (область / окно / экран) |
| `Shift + Print` | Мгновенный скриншот всего экрана |
| `ПКМ` на рабочем столе | Меню управления столом и перенос виджетов |
